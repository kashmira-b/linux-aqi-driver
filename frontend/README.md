# AQI Dashboard

Modern, real-time web interface for visualizing Air Quality metrics.

## Features
- **Real-time**: High-frequency updates via WebSockets (`localhost:8765`).
- **Metrics**: Displays eCO2 (ppm), TVOC (ppb), and Gas Resistance (kΩ).
- **Alerts**: Visual warnings when thresholds are exceeded.

## Usage
Open `index.html` in any modern web browser.

## Tech Stack
- Vanilla HTML5/CSS3
- Pure JavaScript (WebSockets)
